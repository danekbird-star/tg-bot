# Паша — Telegram-бот для бесед

## Запуск
1. Создай бота у @BotFather, получи токен.
2. **Важно:** в BotFather → `/mybots` → твой бот → Bot Settings → Group Privacy → **Turn off**, иначе бот не видит обычные сообщения в группе.
3. Скопируй `.env.example` в `.env`, впиши токен и ключ Anthropic.
4. Установи и запусти:
```
pip install -r requirements.txt
python bot.py
```
5. Добавь бота в группу.

## Админка
В личке с ботом (только для `ADMIN_ID`) работает `/help` со списком команд: `/status`, `/chance`, `/on`, `/off`, `/mute`, `/say`, `/talk`, `/rule` и др. Остальным бот в личке не отвечает.

## Как работает
- Используется Gemini, ключи из `GEMINI_KEYS` перебираются по кругу; если ключ упёрся в лимит — берётся следующий.
- Отвечает, если его тегнули, ответили на его сообщение, написали «Паша», или случайно (`REPLY_CHANCE`, по умолчанию 25%).
- Помнит последние 30 сообщений чата (в памяти, после перезапуска забывает).
- Лимит упоминаний Beatles/Stones — 3 в сутки, считается в коде.
- Характер и лор — в `persona.txt`, правь как хочешь.
